## ⚙️ How to Run the Projects

1. Clone this repository.
2. Open the required project folder.
3. Compile the C source file using GCC.
4. Execute the generated program.

Example:

```bash
gcc finance.c -o finance
```

Run on Windows:

```bash
finance.exe
```

Run on Linux:

```bash
./finance
```
