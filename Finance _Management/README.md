

## 🚀 Features

- Add Income – Record money received.
- Add Expenses – Record daily expenses.
- View Transactions – Display income and expense records.
- Calculate Balance – Calculate the remaining amount.
- Financial Tracking – Monitor financial activities.
- Simple Interface – Easy-to-use menu-driven system.

## 🛠️ Technologies Used

- Compiler: GCC
- Platform: Windows / Linux

- Switch Case

## 💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Compile the C program:

```bash
gcc finance_management.c -o finance_management
```

4. Run the program:

```bash
./finance_management
```

For Windows:

```bash
finance_management.exe
```
